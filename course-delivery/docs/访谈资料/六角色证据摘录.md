# 六角色访谈事实摘录（非逐字稿）
来源：仓库 docs/design.md 历史模拟案例24/36条事实。当前练习林亦舟有3轮原文；其他角色完整原始对话尚未取得。

## 顾明岚
- research-procurement-f00：管理目标：18天降至10天；紧急采购占比27%降至低于12%。
- research-procurement-f01：申请、库存核查、比价、审批、验收；节点耗时未测量。
- research-procurement-f02：试点设想20种常用试剂、6周、规格审核准确率目标至少98%。
- research-procurement-f03：初始预算12万元含集成、培训、验证，维护与人工复核成本需计入。
- research-procurement-f04：安全负责人对上线有否决权。

## 林亦舟
- research-procurement-f10：规格相近、货期不同，反复确认浓度和包装。
- research-procurement-f11：冷藏试剂周五到货无人验收，次日发现温控记录缺失。
- research-procurement-f12：访谈转述160申请/月、平均4轮核对、每轮20分钟，需核实口径。
- research-procurement-f13：高峰期使用既有终端，需草稿保存和同步时间。

## 唐映秋
- research-procurement-f20：节点需输入、输出、负责人和退回原因。
- research-procurement-f21：材料包括规格、三份报价、危险品清单、温度日志。
- research-procurement-f22：采购不得代替安全签署或自主选择供应商。
- research-procurement-f23：交接应包含编号、版本、状态、未决事项并经接收人确认。

## 秦芮
- research-procurement-f30：采购平台、ERP和库存表权限分离。
- research-procurement-f31：CAS、品名与供应商SKU存在标识映射问题。
- research-procurement-f32：系统数据可读；不得自动付款或危险品审批。
- research-procurement-f33：歧义记录进入人工修复队列。

## 傅景
- research-procurement-f40：危险品资质、冷链验收和预算审批不可绕过。
- research-procurement-f41：仅授权角色可查看原始记录。
- research-procurement-f42：发生安全条件时应暂停试点。
- research-procurement-f43：模拟记录暂定保留90天，实际期限待确认。

## 叶书
- 无可核对的该角色逐字访谈；待从训练平台导出。

## 角色待核
- research-procurement-f51：按业务单测量交接等待与重复联系，固定统计口径。
- research-procurement-f53：投诉关联业务编号与版本。
- research-procurement-f54：不承诺未经确认的赔偿或结果。
