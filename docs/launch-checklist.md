# 科研采购助手试点上线检查（均待验证）

下表为验收计划，尚无真实组织数据、供应商合同和生产环境，不能视为上线批准。

| 维度 | 检查项 | 负责人 | 验证方法 | 通过标准 |
|---|---|---|---|---|
| 数据安全 | 身份与会话归属 | 系统负责人 | 跨账号访问测试 | 无越权记录可见 |
| 数据安全 | 文档和采购资料权限 | 安全负责人 | 按角色抽查原文与附件 | 未授权角色不能访问 |
| 数据安全 | 数据外发 | 数据负责人 | 检查供应商合同和请求内容 | 仅经批准数据外发 |
| 数据安全 | 日志与留存 | 合规负责人 | 对照制度抽查记录和清除任务 | 符合批准的期限与范围 |
| 数据安全 | 密钥与备份 | 运维负责人 | 检查密钥存储及恢复演练 | 无硬编码密钥，恢复成功 |
| 并发限流 | 模型配额 | 运维负责人 | 模拟配额耗尽 | 请求受控且提示明确 |
| 并发限流 | 接口限流 | 后端负责人 | 按角色压力测试 | 超限稳定拒绝 |
| 并发限流 | 数据库并发 | 数据库负责人 | 并发读写测试 | 不发生重复或丢失确认 |
| 并发限流 | 流式连接 | 后端负责人 | 多连接与断线测试 | 可回收资源且无半轮污染 |
| 并发限流 | 性能基线 | 项目负责人 | 用试点规模测延迟 | 达到业务方确认的目标 |
| 异常兜底 | 模型超时 | 后端负责人 | 注入超时 | 显示中文失败提示且可重试 |
| 异常兜底 | 检索无结果 | 知识库负责人 | 输入制度外问题 | 明确未找到，不编造 |
| 异常兜底 | 外部数据源故障 | 集成负责人 | 模拟接口中断 | 标记不可用并转人工 |
| 异常兜底 | 缺失安全证据 | 安全负责人 | 输入不完整样例 | 停止相关处理并提示负责人 |
| 异常兜底 | 交接未确认 | 采购负责人 | 中断确认流程 | 保持待接收，不视为完成 |
| 内容安全 | 用户提示词注入 | 安全负责人 | 输入忽略规则等测试 | 不改变权限或执行越权动作 |
| 内容安全 | 文档提示词注入 | 知识库负责人 | 上传模拟恶意文档 | 文档指令不获得系统权限 |
| 内容安全 | 引用准确 | 采购负责人 | 人工核验回答与条文 | 引用可定位且支持结论 |
| 内容安全 | 安全与预算越权 | 安全负责人 | 模拟要求跳过审批 | 不批准并转人工 |
| 内容安全 | 工具参数校验 | 后端负责人 | 篡改申请版本和接收人 | 服务端拒绝越权或过期请求 |
| 回滚 | 版本记录 | 运维负责人 | 检查发布记录 | 可定位代码、规则、模型和制度版本 |
| 回滚 | 应用回退 | 运维负责人 | 试点环境演练 | 按约定时间恢复上版 |
| 回滚 | 数据恢复 | 数据库负责人 | 备份恢复演练 | 核对关键记录完整 |
| 回滚 | 制度回退 | 知识库负责人 | 撤销错误文档版本 | 旧版恢复，错误版本不再检索 |
| 回滚 | 停用与沟通 | 项目负责人 | 演练安全停止和通知 | 明确责任人、停用条件和通知渠道 |
