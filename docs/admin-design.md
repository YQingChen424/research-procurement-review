# 科研采购后台设计（待实现）

## 页面与权限

| 页面 | 角色 | 功能 |
|---|---|---|
| 登录 | 全部 | 企业身份系统或试点账号登录，取得短期访问令牌。 |
| 制度管理 | 管理员 | 上传 Markdown/PDF，查看处理状态与版本、发布或停用；源文件及派生索引受权限控制。 |
| 提示词管理 | 管理员 | 维护、预览和发布带版本的制度问答模板；不可覆盖服务端固定安全规则。 |
| 对话审计 | 授权审计员 | 按用户、时间过滤记录，标记疑似绕过审批或伪造证据；标记仅为待核实线索。 |
| 采购审核与交接 | 申请人、采购审核人、安全人员 | 根据现有角色权限查看申请、审核快照及确认交接；业务操作不因技术管理员权限自动授权。 |

## 接口草案

| 方法与路径 | 权限 | 内容 |
|---|---|---|
| `POST /auth/login` | 未登录 | 验证凭据并签发短期 JWT；正式账号、密钥管理与企业身份系统待确认。 |
| `GET /auth/me` | 登录用户 | 返回账号与业务角色。 |
| `POST /admin/documents` | 制度管理员 | 上传文件，登记草稿版本并异步解析、分段和构建索引；失败展示原因。 |
| `GET /admin/documents` | 制度管理员 | 分页列出文档、版本、来源和处理状态。 |
| `POST /admin/documents/{id}/publish` | 授权发布人 | 检查解析结果、权限和有效期后发布；记录变更。 |
| `POST /admin/documents/{id}/retire` | 授权发布人 | 停用检索并保留审计记录；物理删除依保留政策另行设计。 |
| `GET /admin/prompt-templates` | 管理员 | 读取当前和历史模板。 |
| `POST /admin/prompt-templates` | 管理员 | 保存新草稿和版本。 |
| `POST /admin/prompt-templates/{id}/publish` | 管理员 | 发布模板，新请求立即使用；记录发布人和时间。 |
| `GET /admin/audit/conversations` | 授权审计员 | 按时间和用户筛选并分页；记录审计访问。 |
| `POST /admin/audit/messages/{id}/flags` | 授权审计员 | 记录人工复核标记和原因，不自动判定违规。 |

默认模板建议：“你是科研采购制度助手，只根据提供的制度条文回答，不确定时明确说‘制度中未找到’，回答末尾附引用来源，不得编造采购、安全或冷链要求。涉及危险品、预算和冷链事项时提示授权人员复核。”固定工具权限、禁止审批和防注入约束由服务端实施，管理员模板不能取消。

## 目前状态

已有演示 Bearer 令牌、制度文本录入/停用及普通用户会话查询。现已实现试点 JWT 登录、Markdown/PDF 文本上传、模板发布、管理员审计界面以及基础角色校验；详见 [试点指南](pilot-api.md)。发布即生效，未提供独立草稿发布流。企业身份对接、独立审计角色、文档级授权、正式迁移、令牌撤销、OCR 与保留策略仍未完成。
