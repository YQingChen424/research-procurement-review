# 评测样例说明

`procurement_cases.json` 包含 30 条**人工设计的预期用例**，针对虚构制度与规划中的工具接口。它们不是模型实测成绩；工具调用样例所列接口尚未实现。多轮问题用字符串数组表示。执行正式评测前，应准备标注人员、正确答案依据、版本、运行环境及判分规则，并区分未执行、通过和失败。

## 本地运行模拟评测

在项目根目录执行 `python scripts/run_evaluation.py`。程序使用临时数据库和虚构制度，不访问真实模型；输出到已忽略的 `evaluation/runs/latest.json`，记录时间、Git 版本、工作区状态、用例及智能体源码哈希、预期工具、实际工具、事件和错误。工具顺序比较只代表顺序是否一致，不能代表回答正确率或安全合规。

当前脚本运行 25 条单轮用例和 5 条聊天多轮用例；多轮只验证本地指代检索的实际输出，需要人工判断结果是否正确。智能体运行接口本身尚未支持跨轮上下文。已运行内容标记为 `needs_manual_review`，包括工具有序比较一致的情况；应由评审检查证据、回答和具体场景输入。当前工具用例共享一个模拟申请，不代表已覆盖每条样例描述的不同异常状态。真实模型和组织制度未接入，不能把该报告当作真实模型效果或上线结果。
